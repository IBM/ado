# Active-learning examples

[Build a surrogate model with PKH](PKH.md) covers installation, configuring
the pilot and measurement budget, running the ideal-gas example, inspecting
measurements, and loading the saved predictor to predict pressure for the
remaining configurations. Choose the default Random Forest or an AutoGluon final
predictor with its optional installation and fit settings; the same loading
API supports both.
