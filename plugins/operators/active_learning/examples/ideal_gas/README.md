# Active-learning examples

Collect ideal-gas pressure measurements with either operator:

- [Build a surrogate model with PKH](PKH.md)
- [Build a surrogate model with FLORA](FLORA.md)

Each guide covers installation, configuring the pilot and measurement budget,
running the example, inspecting measurements, and loading the saved predictor
to predict pressure for the remaining configurations. Choose the default Random
Forest or an AutoGluon final predictor with its optional installation and fit
settings; the same loading API supports both.
