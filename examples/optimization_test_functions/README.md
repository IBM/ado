# optimization-test-functions example

Full documentation for this example is on the ado website:

- [Search for best configuration with an optimizer](https://ibm.github.io/ado/latest/user-guide/examples/best-configuration-search/)

## Files in this directory

- `space.yaml` — discoveryspace for the optimization test functions example
- `operation_bayesopt.yaml` — Bayesian optimization operation
- `operation_nevergrad.yaml` — Nevergrad optimization operation
- `point.yaml` — single point experiment for testing
- `custom_experiments/` — custom experiment package (`nevergrad_opt_3d_test_func`)
